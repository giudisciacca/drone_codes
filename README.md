# drone codes
This repository contains the documentations and the set of codes that are used to control a own-made drone.


- Sensors
The sensor currently being utilised is the ICM-29048, featuring three-axes accelerometer, gyroscope and magnetometer.


Upgrades:
- Camera


- Perception 
The perception features a MAgdwick filter. Work is ongoing to substitute the Magdwick filter with an Error Space Kalman Filter.
